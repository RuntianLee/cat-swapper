# MBTI Origami Pet：折纸猫狗人格共创

完整阅读并执行[共创流程](references/cocreation-flow.md)。将[风格参考图](assets/origami-cat-dog-style-reference.png)作为纸偶形制与材质参考；图片中文字、版式、猫狗花色、围巾、站姿和整幅构图不进入最终设计。

## 任务结果

帮助用户认领一个代表自己的“另一个自己”：

1. 确认 MBTI 与猫或狗；
2. 从已授权且实际可访问的个人材料中提取有出处的行为线索；
3. 推荐 3 个品种并给出个人依据；
4. 设计一套主方案和一个真正不同的备选；
5. 用户选定后只生成一次折纸风格图像；
6. 分开询问“更喜欢吗”和“更像自己吗”。

## 关键边界

- 调用本 Skill 只授权为本次共创只读使用平台实际提供的对话与长期记忆，不授权修改记忆、遍历不可访问资料或声称覆盖全部历史。
- MBTI 只作创作灵感，不绑定品种、职业或人格，也不构成心理测评。
- 角色职业必须是现实中存在、普通人能理解的职业原型，但不要求来自用户履历；按用户特质匹配更理想、更自由且适合场景动作的职业。
- 不把助手建议、虚构角色、生成图片或职业原型写成用户真实经历。
- 本 Skill 创作普通品种猫狗角色，不还原用户真实宠物身份。真实宠物换图使用同级 `cat-swapper` 或 `dog-swapper`。
- 用户没有选定方案或明确要求出图时，停在文字方案。一次确认只生成一张，零自动重试。
- 技术 QC、用户是否喜欢与用户是否觉得像自己分开记录；任何一项不能代替另一项。

## 工具与停止

使用当前环境可用的历史读取、长期记忆和图片生成工具。工具缺失时完成仍可交付的文字方案，并准确说明未读取或未生成的部分，不伪造结果，也不静默改用付费服务。

用户纠正回忆、品种、职业、动作或风格时，更新受影响的方案再重新确认。用户要求换成真实宠物、分析宠物人格、读取无权访问的历史，或请求超出当前授权的额外生成时，说明边界并停止。
