# Cat Swapper：猫咪壁纸替换

根据唯一基础图中的待替换猫数量选择恰好一个模式。用户已经明确图片职责、猫位和目标时，不重复询问。

## 模式选择

- 基础图中恰好一只待替换猫：完整阅读并执行[单猫流程](references/single-cat.md)，只使用 `prompt.txt`。不得读取或拼接多猫流程及 `prompt-multi.txt`。
- 基础图中有两只或更多待替换猫：完整阅读并执行[多猫流程](references/multi-cat.md)，只使用 `prompt-multi.txt`。不得读取或拼接单猫流程及 `prompt.txt`。
- 待替换猫数量、猫位、参考图片职责或一对一映射不清楚：说明具体缺口并请求补充；不得猜测模式、身份分组或映射关系。

以上引用路径相对于本 `SKILL.md` 解析。选中模式的引用文件或提示词缺失时，报告具体缺失路径，不得用另一模式代替。

## 共同边界

- 本 Skill 只包含指令，不提供图片模型、API 密钥、付费调用授权或服务商配置。
- 启用 Skill、查看附件或准备提示词，都不等于获得付费模型调用授权。
- 不得使用生成图或合成壁纸作为身份参考；每张参考照片必须能明确归属到唯一目标猫。
- 本流程仅用于猫换猫。基础图主体或身份参考属于其他物种时，说明冲突并请求澄清；不得擅自切换 Skill 或尝试跨物种替换。
- 用户未要求生成时，只完成准备工作。多猫文本支持不证明任何图片工具能够接收任意数量的图片或稳定保持多个身份。
- 保护每张输入图片的隐私和使用权。
- 提示词要求严格保留非猫区域，但生成模型不保证这些区域逐像素不变。
