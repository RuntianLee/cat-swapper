# Cat Swapper：猫咪壁纸替换

先按猫数量和画面关系选择恰好一个模式。用户已经明确图片职责、猫位和目标时，不重复询问。

## 模式选择

- 基础图中恰好一只待替换猫：完整阅读并执行[单猫流程](references/single-cat.md)，只使用 `prompt.txt`。
- 基础图中有两只或更多待替换猫，且猫位可独立裁出、身份隔离或非猫区域保持优先：完整阅读并执行[分层多猫流程](references/layered-multi-cat.md)。该模式逐猫使用 `prompt.txt`，不读取或拼接 `prompt-multi.txt`。
- 基础图中有两只或更多待替换猫，且存在复杂接触／遮挡／共享阴影，用户明确要求单次直出，或当前环境没有可靠本地抠像与 alpha 合成能力：完整阅读并执行[一次性多猫直出流程](references/multi-cat.md)，只使用 `prompt-multi.txt`。
- 用户明确选择某一种多猫模式时优先遵循；若选择与当前工具能力冲突，说明缺口并停止，不静默换模式。
- 待替换猫数量、猫位、参考图片职责、一对一映射或猫际关系不清楚：说明具体缺口并请求补充；不得猜测模式、身份分组或映射关系。

以上路径相对于本 `SKILL.md` 解析。选中模式的引用文件或提示词缺失时，报告具体缺失路径，不得用另一模式代替。不同模式不得拼接执行。

## 共同边界

- 本 Skill 只包含指令，不提供图片模型、API 密钥、付费调用授权、抠像模型或服务商配置。
- 启用 Skill、查看附件、准备提示词或准备本地脚本，都不等于获得付费模型调用授权。
- 不得使用生成图、透明猫层或合成壁纸作为身份参考；每张身份参考必须是原始照片，并明确归属到唯一目标猫。
- 本流程仅用于猫换猫。基础图主体或身份参考属于其他物种时，说明冲突并请求澄清；不得擅自切换 Skill 或尝试跨物种替换。
- 用户未要求生成时，只完成准备工作。多猫文本或分层流程支持不证明任何模型、抠像器或合成环境能够稳定保持多个身份。
- 每次外部模型调用都必须由当前授权覆盖；默认零自动重试，不擅自增加请求、切换模型或扩大成本。
- 技术 QC、主人身份判断与整体审美接受分开记录。主人接受不能覆盖技术失败，技术通过也不能代替主人判断。
- 保护每张输入图片的隐私和使用权。
- 文本提示词不能保证非猫区域逐像素不变；需要硬性像素保持时，优先使用分层模式并验证 alpha 并集之外的像素。
