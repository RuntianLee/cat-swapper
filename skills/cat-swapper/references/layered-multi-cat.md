# 分层多猫流程

适用于两只或更多目标猫，且各猫位可以独立裁出。目标是把身份生成限制在每只猫的局部小图中，再用本地透明层合成，避免多身份同时输入导致串位，也避免把多张有色差的整图结果直接蒙版拼接。

## 必需输入与能力

- 恰好一张基础壁纸，其中包含两个或更多可定位猫位；
- 每只目标猫各自独立的一组原始身份照片；
- 每个基础猫位到唯一身份组的一对一映射；
- 能生成无猫底图和逐猫局部小图的图片模型；
- 能导出带 alpha 的本地抠像工具与确定性图像合成环境；
- 用户明确要求实际生成时，当前授权覆盖全部计划调用的模型、请求上限和最坏成本。

猫位无法独立裁出、存在复杂身体交叠、共享道具、接触动作或共享阴影时，停止并建议改用[一次性多猫直出流程](multi-cat.md)；不得为了套用分层流程而破坏原图关系。

## 1. 冻结画布、猫位与身份组

1. 先确定最终画布尺寸、比例和需要避让的系统安全区。
2. 为每个基础猫位记录稳定编号、原图裁片框、目标主体框、动作、表情、头部方向、前后层级与遮挡关系。
3. 每只目标猫的原始照片组成独立身份组；一张照片不得跨组复用。生成图、合成图和透明猫层不得进入身份组。
4. 逐猫冻结局部请求尺寸。尺寸应覆盖最终画布中该猫所需的有效像素和少量抠像余量，不为一个小猫位生成整张大画布。

## 2. 冻结调用合同

可以逐次授权，也可以用一个总合同覆盖“1 张无猫底图 + N 张局部猫图”。总合同仍须明确：

- 全部输入及 SHA-256；
- provider、精确 model ID、每张输出尺寸与格式；
- 总请求数、总保存数和最坏成本；
- 自动重试、补发、换模型、换尺寸和图层拆分是否允许，默认均为否；
- 失败、结果未知、严重身份错误或达到上限时立即停止。

批量授权只减少中途确认，不得省略每次请求的独立账本、输出哈希和逐猫 QC。

## 3. 生成无猫底图

只把基础壁纸发送给模型，要求删除全部猫并自然补全其后背景：

- 直接使用最终画布尺寸；
- 不需要输出原猫层，也不需要启用图层拆分；
- 不添加新主体、文字、Logo、边框或装饰；
- 检查是否仍有猫残影、背景结构断裂、全图重构或不可接受的非猫变化；
- 若冻结合同把无猫底图设为独立主人闸门，获得明确接受后再继续；若用户已授权整批仅在严重问题时停止，则技术检查无严重问题即可继续，最终仍单独记录主人判断。

若最终需要另一画幅，先在无猫底图上裁切或扩展，再安排猫层；不要先完成整图合成再裁掉边缘猫。

## 4. 逐猫生成局部小图

每次只处理一个猫位：

1. 从基础壁纸裁出当前猫位，保留足够的动作、透视、表情和局部光线信息；尽量排除其他猫。
2. 输入顺序为当前猫位裁片在前，随后只放当前目标猫的原始身份参考。
3. 按[单猫流程](single-cat.md)生成当次表情描述，并拼接完整且不变的 `prompt.txt`。
4. 额外明确只生成当前一只猫，不带入参考照片背景、人物、其他猫或临时物品。
5. 输出普通 RGB 小图即可；不依赖模型直接输出透明层或图层拆分。
6. 先检查身份方向、动作、表情、解剖、肢体、尾巴和意外配饰。严重失败必须停止；抠像不能修复错误身份或姿势。

## 5. 本地抠像

1. 保存原始 mask，再导出 straight/unpremultiplied RGBA PNG。
2. 只有在主体按画面应当连通时，才用最大连通主体过滤相邻猫或背景碎片；合理离散的尾巴、爪子、胡须和飞散毛发不得自动删除。
3. alpha 四边应为 0，避免把局部矩形边界带入最终合成。
4. 在黑底、白底和棋盘格上检查毛发、胡须、孔洞、背景残留、色边和粗光晕。
5. 主体缺失、邻猫残片、明显包边或颜色污染均判为失败；不要宣称任何自动抠像器能够“无损”处理毛发。

## 6. 确定性合成

1. 无猫底图是唯一背景。
2. 按冻结主体框对透明猫层等比缩放和平移，不得非等比拉伸。
3. 按原图前后关系排序 alpha 合成；原场景物体需要遮住猫时，必须保留或重建独立前景遮挡层。
4. 每只猫的有效 alpha 包围盒必须完全在画布内；检查脸部、尾巴、爪子及猫际层次。
5. 计算全部猫层 alpha 并集；并集之外的输出像素必须与无猫底图一致。无法做像素比较时，明确标记为未验证。
6. 手机壁纸额外检查时钟、通知和底部快捷按钮安全区。

## 7. 分层验收与停止

分别记录：

- 传输事实：每次请求、输出、请求 ID、尺寸、SHA-256、重试次数和实际账单未知项；
- 逐猫技术 QC：身份方向、表情、姿势、解剖、配饰和局部生成质量；
- 抠像 QC：主体完整、毛发边缘、残片、孔洞和 alpha 边界；
- 合成 QC：猫数、猫位、层级、全部主体入画，以及 alpha 并集外像素是否为 0；
- 主人判断：逐字记录明确评价维度，不用整体喜欢覆盖技术失败。

任一调用失败或结果未知、身份组串位、严重解剖错误、主体无法完整抠出、合成关系无法还原、请求数或成本达到上限时停止。除非新授权明确覆盖，不自动补发、重试或切换到另一模式。
