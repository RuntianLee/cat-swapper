# Cat Wallpaper Replacement Skill

一个用于“保留原壁纸构图与动作，只替换其中猫咪身份”的开放提示词项目。

## 当前版本

当前为初版，只发布经过有限案例测试的通用提示词 [`prompt.txt`](prompt.txt)。仓库尚未包含可安装的 `SKILL.md`、API runner 或自动化脚本，因此目前不是完整的 Codex Skill。

```text

```

## 使用方式

1. 图 1：唯一待编辑的基础壁纸。
2. 从图 2 开始：同一只目标猫的一张或多张原始身份参考照片。
3. 将 `prompt.txt` 完整、原样地发送给支持多图参考的图片编辑模型。

提示词不绑定特定模型、图片数量、猫咪身份、壁纸场景、分辨率或文件格式。不同模型可能重绘背景、改变尺寸或产生解剖错误，结果仍需人工检查。
